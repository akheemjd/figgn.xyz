How to Use

  1. Add rows with a value and its weight. For example: assignment score 90 with weight 30 (meaning 30% of final grade).
  2. Add or remove rows as needed using the + and × buttons.
  3. Weighted average updates instantly — it's the sum of (value × weight) divided by sum of weights.
  4. Simple average is shown for comparison — the unweighted mean of all values.

How It's Calculated

Formula: Weighted Average = Σ(Valuei × Weighti) ÷ Σ(Weighti)

Example with defaults:

(90×30) + (85×50) + (78×20) = 2,700 + 4,250 + 1,560 = 8,510
8,510 ÷ (30+50+20) = 8,510 ÷ 100 = 85.1
Simple average: (90+85+78) ÷ 3 ≈ 84.3

FAQ

When is weighted average used?

Weighted averages are used whenever some values matter more than others. Common examples: course grades (exams weigh more than homework), stock portfolio returns (weighted by investment amount), survey results (weighted by demographics), and GPA calculations.

Do weights have to add to 100?

No! The calculator works with any weight values. The formula divides by the total weight, so you can use 30/50/20 (sum = 100), 3/5/2 (sum = 10), or any other values. The proportion is what matters.

What's the difference between weighted and simple average?

Simple average treats all values equally: sum of values ÷ count. Weighted average gives more importance to values with larger weights. For example, if an exam counts for 60% and homework counts for 40%, the exam score affects your grade 1.5× more than homework.
